# Windows

Do not run RNS here.

Windows Mobile Hotspot and Internet Connection Sharing can share a connection. They cannot force SSID `RNS`, force channel 6, redirect new phones to a voucher page, bind a MAC, expire it, and kick it.

WSL cannot own the Wi-Fi radio, so the Linux scripts in `../linux/` cannot create the access point from inside Windows. A virtual machine with a USB Wi-Fi stick is a lab trick, not a 24/7 shop.

Nothing in this folder should be treated as the product. Notes and failed experiments only.
